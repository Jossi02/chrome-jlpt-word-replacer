## 비고

- D3-2에서 사전 646개로 줄고 `matcher.js`에 예외가 하나 늘었지만, `scope.js`·`replacer.js`·`content.js`는 이번 회귀에서 전혀 건드리지 않았다 — 항목 1·2·6은 원래 D1/D2에서 이미 검증된 코드 경로이며 이번엔 D3-2 변경이 회귀를 만들지 않았음을 재확인한 것이다.
- 항목 5(한 눈에 8개)에서 스크린샷 캡처 해상도(약 698px)가 실제 브라우저 뷰포트(911px)보다 작아 시각적으로 오판할 뻔했다 — 이후 실측은 전부 `window.innerHeight` + `getBoundingClientRect()` 기준으로 다시 확인했다. 스크린샷만으로 "첫 화면" 개수를 셀 때는 이 점을 주의할 것.

**결론: 18칸 표가 (해당없음 1칸을 제외하고) 전부 ○ — D3-4로 진행 가능.**
