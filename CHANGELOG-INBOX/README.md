# CHANGELOG-INBOX — 남의 소유 파일을 건드렸을 때 남기는 쪽지함

## 왜 있나

`.claude/settings.local.json` 의 `deny` 가 남의 파일 수정을 **막는다.**
그런데 진짜 급할 때가 온다 — 내 매처가 안 도는데 원인이 `src/scope.js` 에 있을 때.

그때 규칙은 **"절대 안 된다"** 가 아니다. **"뚫어도 되지만 흔적을 남겨라"** 다.

> **하네스는 금지가 아니라 추적이다.**

`deny` 는 잠금장치가 아니라 안전벨트다. AI 에게 "막아줘" 가 되면 "풀어줘" 도 된다.
실수는 막지만 의도는 못 막는다. **훅만 안 뚫린다 — 대신 기록만 남긴다.**

## 어떻게 만들어지나

`.claude/hooks/owner-guard.mjs` 훅이 **자동으로** 만든다.
`.claude/owners.json` 기준으로 내 레인 소유가 아닌 파일을 고치는 순간 여기에 `.md` 가 하나 생긴다.

```
0819-1430-A.md
월일-시분-레인
```

같은 분에 여러 파일을 고쳤으면 한 쪽지의 목록에 덧붙는다.

## 내가 할 일

쪽지가 생기면:

1. **빈칸을 채운다** — 왜 고쳤나 / 되돌리는 법
2. **담당자에게 알린다** — PR 본문이나 이슈. 담당자는 `OWNERS.md` 에서 확인
3. 담당자가 확인하면 체크박스에 체크

## 담당자가 할 일

PR 을 받으면 이 폴더를 본다. **내 소유 파일 관련 쪽지가 있으면 읽는다.**
확인이 끝난 쪽지는 지운다.

## 통합자(C)는 다르다

통합자는 `deny` 가 없다 → **통합자의 모든 소유 밖 수정이 여기 쌓인다.**
그게 **통합 리포트**다. 지우지 말고 3일차 발표 때 개발 과정의 증거로 쓴다.

## 레인이 설정돼 있어야 돈다

훅은 `KOJA_LANE` 으로 내가 누구인지 안다. 설정 안 하면 **쪽지가 안 생긴다.**

```
cp .claude/lane-templates/A.json .claude/settings.local.json    # 자기 레인으로
```

`OWNERS.md`「하네스 켜기」 참고.
